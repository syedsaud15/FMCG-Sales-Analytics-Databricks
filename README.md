# FMCG Sales Analytics — Databricks Dashboard Gallery

This repository is a compact evidence gallery for an FMCG sales dashboard built in Databricks SQL, including KPI, brand, category, query, and Genie AI views.

> The notebooks, sample data, Delta Lake transformations, incremental-load logic, architecture, and dashboard export are available in the full [FMCG Lakehouse Data Engineering Pipeline](https://github.com/syedsaud15/databricks-data-ai-project). Recruiters should use that repository to review the implementation.
