# 🛒 FMCG Sales Analytics Dashboard using Databricks

## 📌 Project Overview

This project demonstrates an end-to-end FMCG Sales Analytics solution built using Databricks SQL and Genie AI.

The dashboard provides business insights into sales performance, brand performance, category performance, and KPI metrics using interactive visualizations.

---

## 🚀 Technologies Used

- Databricks SQL
- Databricks Dashboards
- Databricks Genie AI
- SQL
- Data Analytics

---

## 📊 Dashboard Features

### 1️⃣ Category Analysis

- Total Sales by Category
- Sales Comparison
- Category Performance

---

### 2️⃣ Brand Analysis

- Brand-wise Sales
- Top Performing Brands
- Sales Comparison

---

### 3️⃣ KPI Dashboard

- Total Sales
- Total Brands
- Total Categories
- Average Sales

---

## 🤖 Genie AI Features

The Databricks Genie AI assistant can answer business questions such as:

- What is the total sales?
- What is the average sales?
- Which category has the highest sales?
- Show top 5 brands by sales.
